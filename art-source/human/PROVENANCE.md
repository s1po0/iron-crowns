Repository: https://github.com/makehumancommunity/makehuman

The upstream mesh header and bundled asset license expressly release this mesh under **CC0 1.0 Universal**. The MakeHuman application's separate AGPL program code is not used or redistributed here.

`../../scripts/build-human-mesh.py` is an original extraction/conversion tool. It produces a head and scalp mesh in Godot coordinates. The rest of the current armor/limb rig remains procedural; this change must not be described as a fully replaced, professionally animated human body or as matching the reference screenshots.
